# 🌄 Surya-Inspired Gallery

A visually rich, Everest-inspired photo gallery created with HTML and CSS. This is a tribute to wanderlust, nature, and soulful travel photography.

## ✨ Features

- Full-screen background with dark overlay
- Modern, glowing typography
- Animated, responsive image gallery
- Malayalam and Tamil language elements
- Clean and elegant mobile design

## 📸 Live Preview

> To view locally, open `index.html` in any browser.

## 📂 How to Use

1. Clone or download the ZIP file of this repo.
2. Replace the image URLs in `index.html` under the `<section class="gallery">`.
3. Add or modify content as needed.

## 🖼 Sample Gallery Images

You can update the image URLs with your own hosted images:
```html
<img src="https://your-image-url.jpg" alt="Your description" />
```

## 📱 Responsive Design

Mobile-friendly using CSS media queries. Optimized for viewing on any device.
